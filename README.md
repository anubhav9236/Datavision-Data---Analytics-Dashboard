 📊 DataVision – Excel Analytics Dashboard

DataVision is a modern and responsive **Data Analytics Dashboard** that allows users to upload Excel or CSV files and transform raw business data into meaningful insights.

The application processes data directly in the browser and presents important business metrics through a clean and easy-to-understand dashboard.

---

##  Features

- 📁 Upload Excel and CSV files
- 📊 Automatically analyze uploaded data
- 💰 Display Total Sales
- 🛒 Display Total Orders
- 📈 Calculate Average Sale
- ⭐ Identify Top Product
- 📋 View complete data in a table
- 📊 Analytics dashboard
- 🔄 Reset dashboard with one click
- ⚡ Client-side data processing
- 📱 Responsive and user-friendly interface
- 🎨 Clean modern dashboard design

---

## 🖥️ Dashboard

The DataVision dashboard provides an overview of business performance after uploading a dataset.

### Dashboard includes:

- **Total Sales**
- **Total Orders**
- **Average Sale**
- **Top Product**
- **Data Table**
- **Analytics Section**
